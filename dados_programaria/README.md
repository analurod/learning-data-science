# 📊 Curso de Análise de Dados | PrograMaria

Repositório com os exercícios, notebooks, consultas SQL e projetos desenvolvidos durante o curso **Análise de Dados da PrograMaria**.

O curso aborda conceitos fundamentais de análise de dados, estatística, bancos de dados, visualização de dados e introdução ao aprendizado de máquina, utilizando ferramentas amplamente adotadas pelo mercado, como **Python, Pandas, SQL, SQLite, Jupyter Notebook e Looker Studio**.

---

## 🎯 Objetivo

Consolidar os conhecimentos adquiridos ao longo da formação por meio da prática com:

- Manipulação e análise de dados;
- Limpeza e tratamento de bases;
- Estatística descritiva;
- Engenharia de atributos (Feature Engineering);
- Banco de dados relacionais e SQL;
- Visualização de dados;
- Construção de dashboards;
- Introdução ao Machine Learning.

---

## 🛠️ Tecnologias Utilizadas

- Python

- NumPy
- Matplotlib
- SQLite
- SQL
- Jupyter Notebook
- Looker Studio
- Excel

## 📚 Conteúdo Programático

### Módulo 1 — Todes a bordo!

Introdução ao curso, à comunidade PrograMaria e à jornada de aprendizagem.

**Principais tópicos:**

- Apresentação da formação
- Networking e comunidade
- Planejamento da jornada de estudos

**Carga horária:** 1h05min

---

### Módulo 2 — Esquentando os motores!

Primeiro contato com análise de dados e conceitos fundamentais.

**Principais tópicos:**

- O que são dados
- Tipos de dados
- Agrupamentos
- Estruturas condicionais (if/else)
- Primeiras análises exploratórias
- Cruzamento de informações

**Carga horária:** 1h04min

---

### Módulo 3 — Primeira Análise

Introdução ao Python para análise de dados.

**Principais tópicos:**

- Instalação do Python
- Conceitos básicos da linguagem
- Algoritmos
- Jupyter Notebook
- Bibliotecas Python
- Introdução ao Pandas
- Leitura e exploração de dados
- Filtros e consultas

**Carga horária:** 3h29min

---

###  Módulo 4 — Análises Estatísticas com Python

Fundamentos estatísticos aplicados à análise de dados.

**Principais tópicos:**

- Estatística descritiva
- Média, mediana e moda
- Valores faltantes (Missing Values)
- Tratamento de dados incompletos
- Outliers
- Distribuições amostrais
- Intervalos de confiança

**Carga horária:** 3h27min

---

###  Módulo 5 — Mais sobre Análises Estatísticas

Aprofundamento em preparação e exploração de dados.

**Principais tópicos:**

- Feature Engineering
- Criação de variáveis derivadas
- Correlação
- Relações entre variáveis
- Interpretação de métricas estatísticas

**Carga horária:** 2h03min

---

###  Módulo 6 — Base de Dados

Introdução a bancos de dados relacionais e SQL.

**Principais tópicos:**

- Integração SQL + Pandas
- SQLite

**Carga horária:** 1h43min

---

###  Módulo 7 — Visualização de Dados

Transformação de dados em informações visuais.

**Principais tópicos:**

- Boas práticas de visualização
- Escolha de gráficos
- Visualização em Python
- Storytelling com dados
- Dashboards
- Looker Studio

**Carga horária:** 2h46min

###  Módulo 8 — Introdução ao Aprendizado de Máquina

Primeiros conceitos de Machine Learning.

**Principais tópicos:**

###  Módulo 9 — Para ir além
